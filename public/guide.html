User guide

New here? Open the illustrated start-up guide →

Welcome

Sign in with Google or email. Ask the church owner or a manager to approve your email, then refresh. Open My songbook for your songs, folders and setlists, or visit Bukchon International Chapel for the main church database.

Plan a worship set

From home, choose Plan a worship set. Name the set and choose Add from library to find personal and church songs. If a song is missing, choose Add new song, paste or enter the chart, then choose Save and add to setlist.

Reorder songs and choose their sounding keys in the set. Edit arrangement saves changes to your personal chart wherever it is used. Choose Save setlist to save the order and keys. Find saved sets under My songbook → Setlists.

Accounts and access

The church owner manages the church database only. Managers approve members and manage their own personal songbooks; they cannot edit church songs. Approved members can read church songs and edit their own personal versions.

Your songs

Create a song in My songbook. Its first saved version is also copied to the church database. Later personal edits and deletion leave that church copy unchanged. To make your own version of a church song, use Copy to My songbook.

Lyrics and chords

Write section labels as # Verse, # Chorus or # Bridge. Put chords in braces, for example {C}Amazing {G}grace. Older chord notation such as [C] and headings such as [Verse] still render.

Copying songs

Open a song and choose Copy → Copy with chords or Copy lyrics. Copy with chords uses the displayed transposed key. Copy lyrics removes chord markers and keeps the section labels. Copying does not change the saved song.

Keys and reading

Use transpose to change the displayed key. In your personal songbook, Save in X as base key makes that transposed version permanent and resets transpose to zero. Reading mode uses pages, arrows and swipes. Tablets and computers use two columns at widths of 700 pixels or more. Text size can be 6–32px. In a setlist, scroll through the charts or use Jump to song.

Folders

Open a folder card to view its songs; use the My Songbook breadcrumb to return. Create folders and assign songs to one folder each. Deleting a folder keeps its songs in All songs.

Personal setlists

Open My songbook → Setlists → New setlist. Search to add songs, reorder them and save. Search personal songs first; when a song only exists in the church database, selecting it automatically makes a personal copy. Opening a setlist restores missing personal songs if their history is available. You can also open a personal song, choose Add to setlist, select a setlist and press Add song, or enter a new setlist name and create it with this song first. It is appended at the end. Saved key overview shows every song and its saved base key in order, including repeats; temporary reading-mode transposition is separate. Start setlist follows your saved song order. The church account has no setlists. Each personal account can create up to 25 setlists; delete an unused one to make room. Received setlists do not count.

Sharing a setlist

Choose Copy setlist link after saving, or use the chain icon on its card. Send the link to your team. They can sign in with an approved songbook account, read the live set, and find it later under Shared with me. To close the link and remove access for link recipients, open Share options → Turn off link.

Save received setlists

Save to my setlists creates an independent personal setlist with the same or a different name. It copies the current order and song versions, reuses exact personal matches, and never overwrites your existing edited versions. Later changes on either side do not change the other. The original received setlist remains live separately.

Copying a setlist

Copy entire setlist copies every song in saved order, with titles. Choose Copy lyrics to omit chords, or Copy with chords to include each song’s saved base key.

Menu and backups

Open Menu for appearance, installation help, account details, access management and this guide. Managers and the owner can Show/Hide registered accounts. Export songs only downloads songs. Complete backup / restore also includes folders, personal setlists and favorites. Access permissions, received setlists and history are not included. Restore adds separate copies; it does not overwrite current work. Repeated restores create duplicates. Keep backup files safe because they contain song lyrics. Importing adds songs and can create duplicates.

History and recovery

Open Song history on an editable song to preview and restore a saved version. Recover deleted songs is on the song list. Recovery keeps the original song ID so setlists find it again, and does not add another church copy. Songs whose folders were deleted remain in All songs. History starts with this update; earlier deletions cannot be recovered. Church history belongs only to the church owner.

Paste chord sheets

For a new song, use the Chart field and choose Chords above lyrics or Formatted chart. Check the key and save. Use Paste chord sheet when editing an existing song. Paste the title, chords above lyrics and section labels. Convert into editor fills the normal editing fields directly. Check and adjust those fields, then save. Chord placement is estimated from spaces. Move the {chord} markers to adjust positions. New-song conversion also checks for an existing church song with the same title, ignoring case and repeated spaces. Use the existing version or keep your own personal arrangement without adding another church copy. Use Open existing song to visit the church version. Overwrite replaces the version in your own editable songbook with the editor content after confirmation; its previous version stays in history. Only the church owner can overwrite church songs. Personal accounts need an existing personal copy to overwrite. Opening another song leaves the unsaved editor. Different songs with the same title need a distinguishing subtitle. Confirm the suggested arrangement key or change it before saving. Relative major/minor keys can be ambiguous. Artist lookup is not performed and category is no longer shown.

Install and updates

Install this website from your browser to use it like an app. Connect for login and any edits. Saved songs and setlists can be read offline. Changes appear after deployment and refreshing the app. If your phone keeps the old app name or icon, remove its home-screen shortcut and install again.

Drafts and screen awake

Unsaved changes trigger a warning before leaving the editor. Choose to discard or stay. Unsaved song fields and unconverted pasted chord sheets are also stored as browser-local drafts. Reopen the same songbook and choose Recover draft. Saved songs stay unchanged until you save; if the original changed, recovery offers a new song. Cancel or Discard draft removes a draft. Sign-out clears drafts. Remember me must stay checked for drafts to survive a fresh browser session; blocked storage may leave only an in-memory draft, as shown by the editor status. Reading mode keeps the screen awake where supported; check its status. Battery-saving or device settings may release the lock.

Offline use

On each device, sign in online and use Menu → Offline use → Save latest for offline. Wait for the saved timestamp. Refresh also saves automatically. Stay signed in, then switch to airplane mode to read saved personal/church songs and setlists, transpose and turn pages. Received setlists use their last saved version. Editing, sharing, history, complete backups and account changes need internet. Reconnect to check access and get newer versions. Signing out clears saved offline data. Browser storage can be cleared by your device; keep downloaded backups too.

October 16 update

Songbooks now use responsive cards and All/A–Z/# title filters. Personal folders open like folders, with a breadcrumb back to all songs. Setlists use cards and show saved keys. Setlist search includes BIC songs and prioritizes personal versions. In the menu, choose My account ID to set a unique, changeable @ID (3–24 letters, numbers or underscores). Church accounts have no account ID. Managers may also use IDs when granting access. Plain pasted titles can precede a section heading; **Title** explicitly marks a title.

Remember me

On the login page, Remember me is checked by default and applies to email and Google login. Keep it checked to stay signed in in the same browser on this device. Uncheck it for a tab-only session. Sign out removes the saved login and offline copies. Private browsing, clearing site data, or browser restrictions can still require a new login.

Setlist drafts, chord positioning and offline checks

Unsaved setlist names and song order are stored in this browser. Open My Setlists → Recover setlist draft, review and save. Names entered from a song’s Create setlist flow are included. If the original changed or was deleted, recover as a new independent setlist. Save, confirmed Cancel/Discard and sign-out clear drafts. Remember me keeps drafts across browser sessions; otherwise they stay in the current tab. Drafts never sync, and blocked/full storage may prevent recovery.

In Add/Edit Song, open Adjust chord positions visually. Drag a chord to a lyric character, or select it and tap the destination. Use arrows for small adjustments, including keyboard left/right on a focused chord. You can move between lyric lines. Undo last move reverses the latest move while its result is still in the editor. Save afterward; positioning alone does not save.

Opening a setlist online refreshes the saved copy. Stay signed in and test airplane mode on this device before worship.

Sort songs

Open Song filters → Sort songs. Choose Title A–Z or Z–A, Date added — newest or oldest first, or Last edited — newest or oldest first. This rearranges matching songs instead of filtering a date range. It works alongside search, folders and the other song filters. Clear song filters returns to Title A–Z.

Older songs with no recorded date added appear last in either date-added direction. Last edited includes saved folder/key changes. Refresh online to update offline copies. Received setlists keep the sender’s order.

Joining and approving requests

After signing in, choose your @ID when prompted, then Save ID and continue. IDs use 3–24 letters, numbers or underscores and can be changed later in Menu → My account ID. Existing personal accounts without an ID are prompted too. The church owner does not need an ID.

New unapproved accounts send an access request after saving the ID. Use Check approval on the waiting screen. If you already have an ID but no request, choose Request access. A declined request keeps your login account; you can contact a manager or choose Request access again.

Managers and the church owner can expand Pending access requests in Menu. Check each person’s name, @ID and email, then Approve or Decline. Approval grants ordinary member access; decline does not delete the account. Names are supplied by the sign-in account. No email notification is sent. Requests refresh while the app is visible, or with Refresh requests.

Menu, sorting and offline-copy recovery

Managers and the church owner can now open Menu → Pending access requests. Show registered accounts also lists @IDs. Inside a songbook, Menu has Export / Import songs first, then Complete backup / restore, then Recover deleted songs.

My Setlists and My folders each have a collapsible Sort control: Name A–Z / Z–A, Date added newest / oldest, and Last edited newest / oldest. This sorts cards, not songs within a setlist. Unknown dates appear last. Folder edit dates track renaming, not edits to contained songs.

In Complete backup / restore, choose Preview last offline save. Review its timestamp, counts and song preview, then Restore offline save as copies and confirm. Current work stays unchanged. This recovers the current songbook's saved songs, folders, personal setlists and favorites, without received lists. Missing song references are reported and skipped. Restoring needs internet, honors the 25-list limit and creates duplicates if repeated.

Only the latest snapshot still on this device is available. Online refreshes replace it and signing out clears it; it is not older-version history. The preview remains fixed if a background refresh happens. Keep downloaded backups too.

Newest setlists and reading content

Personal setlists now start in Date added — newest first order. Folders still start in Name A–Z order. You can change either sort without changing song order within a setlist.

Open Reading mode, then choose Lyrics only or Lyrics + chords. Lyrics only keeps section labels and removes extra chord spacing. Use Reading content to switch while reading; pages are recalculated. The selected mode continues across songs in a setlist. Your saved song stays unchanged.

Edit song sections

In Song Content or Edit raw content, copy a section heading and its lyrics and chords together. Paste the block where you want it in the song. Each copy can be edited independently.

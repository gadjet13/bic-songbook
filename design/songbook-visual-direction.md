# BIC Songbook visual direction

The design uses a neutral canvas, clear type, and a compact header with the existing BIC logo. Purple marks the primary action, the selected navigation item, and keyboard focus. Team and private cue colors retain their current meanings.

- **Typography** uses the device’s system UI font. Song titles and screen titles are prominent. Chords retain their current monospaced treatment.
- **Color** uses a warm gray canvas, white surfaces, and charcoal text in light mode. Dark mode uses near-black charcoal surfaces with light text and a softer purple accent.
- **Spacing** uses 4, 8, 12, 16, 24, and 32 px steps. Toolbars and list rows remain compact. Primary tap targets are at least 44 px.
- **Controls** use a solid primary button, outlined secondary buttons, and red destructive actions. Forms have persistent labels and a visible keyboard focus ring.
- **Navigation** keeps the library tabs and back paths. The reader toolbar leads with song navigation and groups the display controls together.
- **Screens** put planning first on Home, prioritize search and compact rows in the library, center the song order in the setlist editor, and give the chart most of the available height in the reader.

Open [the interactive mockups](songbook-mockups.html) in a browser and use the top controls to switch screens or themes. The layouts reflow at mobile widths. The mockups use fixture charts and names.
